1. 니마갤 인증 가이드

1. 레츠도로에 최초 방문하면 "새로 인증" 페이지가 나옴.

본인의 디시 식별코드를 입력하고, 이용약관 및 개인정보처리방침에 동의한 후 "인증코드 발급받기" 버튼 클릭.




2. 발급된 인증코드를 복사하고, "내 방명록 열기" 버튼을 클릭하여 본인 갤로그로 이동.




3. 본인 방명록에 복사한 인증코드 등록.





4. 인증하기 버튼을 누르기 전에 반드시 설정 아이콘을 클릭하여 "게시글/댓글"을 "공개"로 설정.

이 설정을 하지 않으면 인증을 할 수 없음.

(글댓합 300을 채우지 않더라도 가입가능. 협전 기능만 제한.)







5. 레츠도로 페이지로 돌아와 "인증하기" 버튼 클릭.





6. 마이페이지 > 계정 정보 > 게임 계정 관리 탭에서 로그인에 쓰이는 패스키를 확인 가능.

Google, Discord, X 계정을 연동해서 간편하게 로그인 할 수도 있음.













2. 블라블라 인증 가이드

이제 게임정보 연동을 위해서 블라블라 계정 인증을 해야 함.




1.  마이페이지로 이동한 후, "게임 계정 관리" 탭 -> "계정 추가하기" 버튼 클릭.




2. 블라블라 프로필 초상화를 눌러 프로필로 이동.






3. 브라우저 주소창의 링크나 이미지 상의 ID를 복사.

<<주의>>

인게임 UID가 아님!! 반드시 저 페이지에 있는 20자 가량의 UID를 입력.




4. 레츠도로 페이지로 돌아와 복사해둔 값을 입력.

서버(한섭/일섭/글로벌 등)를 선택한 후 "인증코드 발급받기" 버튼 클릭.




5. 발급된 인증코드를 복사.




6. 복사한 인증코드를 붙여넣고 상태메시지 저장.






7. 레츠도로 페이지로 돌아와서 "인증 시작" 버튼을 클릭하면 인증이 진행됨. 

상태메시지 반영까지 시간이 좀 걸리니 그냥 페이지 나가서 딴거 하고 있어도 됨.





8. 마이페이지 > 게임 계정 관리 탭에서 인증된 블라블라 계정 정보 확인.







3. 인게임정보 연동 가이드


게임정보를 연동하고 채팅방에 들어가야 갤럼들끼리 서로 스탯을 확인할 수 있고,

레츠도로만의 추가 기능(성장추이, 갤 평균 옵작수치 등)도 사용할 수 있음.


1. 블라블라 인게임 프로필 초상화를 클릭하여 프로필 페이지로 이동.





2. 우측 상단의 "자물쇠 아이콘"을 클릭하여 SHIFTYPAD 설정 페이지로 이동.






3. SHIFTYPAD 숨김 설정에서 다음 항목들을 "모두에게 공개"로 설정:


• 홈페이지에 게임 카드(기본 정보)를 표시합니다

• SHIFTYPAD에 전초기지 정보 표시하기

• SHIFTYPAD에 나의 니케 표시하기

• SHIFTYPAD에 유니온 정보 표시하기


이 설정들을 모두 공개로 변경하지 않으면 정보 동기화가 불가능함.






4. 레츠도로 마이페이지로 돌아와 "정보 동기화" 버튼 클릭.





5. 완료 결과 창이 뜸.

실패한 항목이 있으면, 어떤 설정이 안되어있는지 알려줄거니까 그거 보고 다시 ㄱㄱ






4. 협동작전 이용 가이드

이제 협전 사이트 기본 사용방법임.


1. 메인 페이지에서 "티켓 발행" 버튼을 클릭.



그럼 이런 창이 뜰텐데 다 입력하고 "발행하기" 버튼 클릭





2. 채팅방으로 와졌을텐데, 우상단의 "공유" 버튼 클릭.






3. 제목과 본문의 "복사" 버튼을 각각 눌러 복사한 후, 니마갤에 게시글을 작성.



주의: 절대 게시글에 협전 입장코드를 작성해선 안됨. 협전 사이트는 인증된 사용자만 입장코드를 확인할 수 있도록 해서

무분별한 난입과 트롤링을 방지하기 위해 만들어진거임. 게시글에 입장코드를 직접 작성하면 협뚜기의 무단 난입을 막을 수 없어 사이트를 사용하는 의미가 사라짐.


입장코드는 반드시 채팅방 내에서만 공유되어야 함.




4. 협동작전을 시작하기 전, 우측 하단의 "이륙" 버튼을 눌러주면 좋음.

중간에 채팅방에서 나가지더라도, 이륙 시점의 참가자만 재입장이 가능하기에 혼선을 줄일 수 있음.
